Configure steakOS for privacy

Not legal advice. You (the operator) are the controller for personal data on this self-hosted instance. steakOS does not certify your compliance.

Controller role

  • You run the instance and hold keys (self-host / appliance).
  • Enable people (HR) only if you need it — or stay on Copper without HR.
  • Setup requires a privacy acknowledgement before HR is enabled.

Where data lives

AreaExamples
HR / peopleHR file, candidates, time, payroll lines
SalesCustomer names, contacts
UsersLogin accounts, roles
AgentsKeep bulk HR denied; human approval for risky actions

Practical checklist

  1. Change default admin password on shared networks.
  2. Few admin accounts; limit who sees HR.
  3. Collect only data you need for employment and operations.
  4. Backup the database; test restore.
  5. For access requests: export one person from HR desks; finance retention may limit full erase.
