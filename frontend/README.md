# steakOS frontend

Operator screens for steakOS. The local dev server proxies API calls to the backend on port **6060**.

```bash
cd frontend
npm install
npm run dev   # http://localhost:9001
```

Onboarding tour assets live in `public/tour/` (also copied to `src/main/resources/static/tour/` for jar serving).

Product design docs and branding originals are **not** in this tree — see the private companion repo beside this monorepo.
