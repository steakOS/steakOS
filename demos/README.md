# Filmed demo walkthroughs

Browser-captured GIF/MP4 tours of the kitchen-sink **demo companies** (restaurant and professional-services showcases).

| Demo | Folder |
|------|--------|
| **Orange Steak House** (restaurant) | [`steakhouse/`](./steakhouse/) |
| **Heard & Cook Architects** | [`architects/`](./architects/) |

Each demo folder contains:

- `walkthrough.gif` / `walkthrough.mp4` — annotated slideshow
- `frames/` — raw + annotated PNGs
- `manifest.json` — step titles + hints
- `README.md` — re-capture notes

Operator narrative guides and capture script sources live in the **private companion** documentation set. Re-capture helpers used from this tree are under `frontend/` when present; otherwise follow each demo folder’s README.
